# [stop-test-1793253500] Web

The web tier is a Next.js 16 frontend built with React 19 and styled with Tailwind CSS, running on port 3000. It provides the user interface for the task manager application and communicates with the API tier to fetch and manipulate task data. The web application uses server actions for seamless client-server communication and is fully containerized for deployment. It is the only service exposed to the host browser and serves as the primary entry point for end users.
